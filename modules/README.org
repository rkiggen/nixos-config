* Introduction

This directory contains the composable feature modules of my NixOS configurations. Each host (see =hosts/<hostname>/default.nix=) imports the modules it needs; =common.nix= is always included via =flake.nix= and never needs to be imported manually.

The general rule: whenever a specific application (or group of related applications) needs elaborate configuration or brings its own dependencies, it gets its own module. Simple package lists live in the module matching their category.

All modules follow the same shape: they take the special arguments provided by =flake.nix= (=userName=, =hostName=, =nixpkgs=, ...) and configure everything under =config=. Packages are selected through the per-host channels:

#+begin_src nix
nixpkgs.from.stable.vlc      # this host's stable channel
nixpkgs.for.rider.jetbrains.rider  # a channel pinned for one specific package
#+end_src

* Core modules

| Module           | Purpose                                                                        |
|------------------+--------------------------------------------------------------------------------|
| =common.nix=     | always included: user account, timezone, locale, nix/gc settings, minimal tools, SSH host key for agenix |
| =agenix.nix=     | installs the agenix CLI for creating/editing secrets                           |
| =system-hardening.nix= | firewall defaults and ClamAV antivirus engine (daemon + signature updates) |

* Desktop

| Module        | Purpose                                                                              |
|---------------+---------------------------------------------------------------------------------------|
| =xfce.nix=     | XFCE desktop environment, LightDM with slick greeter (WhiteSur theming), Thunar, keymap |
| =i3.nix=       | i3 window manager (used alongside XFCE), plus WM helper tools (autorandr, picom, dunst, feh) |
| =xorg.nix=     | X11 command line utilities (wmctrl, xdotool, xclip, xcolor, ...)                       |
| =rofi.nix=     | rofi application launcher                                                             |
| =fonts.nix=    | additional fonts                                                                      |
| =kdeconnect.nix= | KDE Connect for phone/desktop integration (sharing, notifications, ...)             |
